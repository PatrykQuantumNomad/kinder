# Phase 57.3 Plan 01: Cert-Regen Recovery — Code + Tests Summary

**One-liner**: Widened `RegenerateEtcdPeerCertsWholesale` to renew all 4 etcd-adjacent certs with active etcdctl + apiserver health-gates, IPv6-aware loopback, post-pass expiry verify, diagnostic dump on failure, and `--strategy` cobra flag for direct operator invocation.

## What Was Built

### Task 0 — Diagnostic Capture + Cert-Set Lock (commit `9fb9693b`)

Captured 3 diagnostics from live `uat-58-01` cluster and appended verbatim to `57.3-CONTEXT.md`:
- `ls -la /etc/kubernetes/pki/etcd/` → `peer.crt` mtime 12:47 (just regenerated), all others 12:42 (NOT regenerated)
- `docker exec cp1 crictl exec $(crictl ps | grep etcd) etcdctl endpoint health` → both probes failed
- `openssl x509 -noout -text -in /etc/kubernetes/pki/etcd/server.crt` → SAN contains `172.19.0.4` but container is at `172.19.0.3`

Cert-set locked: `["etcd-peer", "etcd-server", "etcd-healthcheck-client", "apiserver-etcd-client"]`. Cluster deleted.

### Task 1 — Widen certregen.go (commit `7257a365`)

Rewrote `pkg/internal/lifecycle/certregen.go`:
- Added `certCycle` struct and `cycleForCertType` map routing each cert to its static-pod manifest
- Added `etcdHealthChecker` and `apiserverHealthChecker` package-level test-injection vars (mirrors `certRegenSleeper`)
- Added `renewAndCycleOne()` helper: kubeadm renew → mv manifest out → wait 2s → mv manifest back → etcd/apiserver health gate
- Widened `RegenerateEtcdPeerCertsWholesale`: pre-snap → 4×renewAndCycleOne per CP → post-pass verify
- IPv6-aware loopback: `loadbalancer.ClusterIPFamily()` → `[::1]:2379` / `[::1]:6443/healthz` vs `127.0.0.1`
- On any failure: `dumpCertRegenDiagnostics` (etcdctl member list, check-expiration, crictl logs, serial table) then hard-fail with "Cluster state is undefined — delete and recreate the cluster"

### Task 2 — Test matrix in certregen_test.go + resume_test.go fixes (commit `0a5741c8`)

Added to `pkg/internal/lifecycle/certregen_test.go`:
- `TestRegenerateEtcdPeerCertsWholesale_HappyPath` (42 node.Command calls, 9 etcd checker, 3 apiserver checker)
- `TestRegenerateEtcdPeerCertsWholesale_IPv6Endpoint` (verifies `[::1]:2379` and `[::1]:6443/healthz`)
- Error path tests: EtcdHealthGateTimeout, ApiserverHealthGateTimeout, KubeadmRenewError, PostPassVerifyFailure
- `TestRegenerateEtcdPeerCertsWholesale_SingleCP_NoOp`, `_PerCertManifestRouting`
- `TestParseCheckExpiration_*`, `TestParseEtcdHealth_*`
- `TestRegenerateEtcdServerCert_RealX509Verify_LoopbackHandshake` (SC4): real `crypto/x509` chain verify + `tls.Listen`/`tls.Dial` over loopback, table-driven IPv4+IPv6

Updated `pkg/internal/lifecycle/resume_test.go` to add `withEtcdHealthChecker`/`withApiserverHealthChecker`, fix `haTestCmder` ip-family/strategy label ordering, and add alternating pre/post check-expiration JSON responses.

### Task 3 — --strategy cobra flag (commit `590d1a0e`)
