### DEVIATION Audit: `pkg/cluster/loadbalancer/lbconfig.go` Bridge Package

**Background:** Go's internal package rule prevents `pkg/internal/lifecycle` from importing `pkg/cluster/internal/loadbalancer` directly (different subtree roots). The plan prescribed a direct import; this is impossible without violating Go module semantics.

**What was built:** A non-internal bridge package at `pkg/cluster/loadbalancer/lbconfig.go` that re-exports `WriteDynamicConfig` as a single-line delegate:

```go
func WriteDynamicConfig(node nodes.Node, cps []nodes.Node, ipv6 bool) error {
    return internallb.WriteDynamicConfig(node, cps, ipv6)
}
```

**Assessment: ACCEPTABLE WORKAROUND**

Rationale:
1. The bridge is a pure delegate — no logic added, no behavior divergence possible
2. Single source of truth is preserved in `pkg/cluster/internal/loadbalancer/config.go`
3. The bridge package has no test files and no state; it cannot independently introduce bugs
4. The SUMMARY correctly documents this as a Rule 1 auto-fix (blocker during execution, auto-resolved)
5. The alternative (moving `WriteDynamicConfig` out of `internal/`) would widen the API surface of the package unnecessarily
6. This pattern is a standard Go idiom for internal-package access across subtree boundaries

**No gap created.** The deviation preserves the D-lock 3 intent (single canonical implementation) while respecting Go module constraints.
