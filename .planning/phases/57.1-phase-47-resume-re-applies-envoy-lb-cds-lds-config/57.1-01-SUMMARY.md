## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Import cycle: loadbalancer cannot import providers/common**
- **Found during:** Task 1
- **Issue:** The plan specified importing `sigs.k8s.io/kind/pkg/cluster/internal/providers/common` for `APIServerInternalPort`. However, `providers/common/images.go` already imports `pkg/cluster/internal/loadbalancer` (for `loadbalancer.Image`). Adding the reverse import would create a cycle: `loadbalancer → providers/common → loadbalancer`.
- **Fix:** Added `apiServerInternalPort = 6443` private constant to `const.go`, mirroring `common.APIServerInternalPort`. Also added `const.go` to the Task 1 commit (plan specified only `config.go`).
- **Files modified:** `pkg/cluster/internal/loadbalancer/const.go`
- **Commit:** 97048452

**2. [Rule 2 - Test count mismatch] nodeutils.WriteFile issues 2 calls (mkdir + cp), not 1**
- **Found during:** Task 3
- **Issue:** The plan's Test 3 and Test 4 expected `errs` slices and `len(calls)` assertions were based on WriteFile = 1 call. Actual `nodeutils.WriteFile` makes 2 calls per file: `mkdir -p <dir>` + `cp /dev/stdin <dest>`. So for LDS+CDS+sh the full sequence is 5 calls (idx 0-4), not 3.
- **Fix:** WriteFileError test uses `errs: []error{fmt.Errorf("disk full")}` (mkdir for LDS fails at idx 0) — `len(calls)==1` still holds. MvError test uses `errs: []error{nil, nil, nil, nil, fmt.Errorf("permission denied")}` (sh at idx 4) — asserts `len(calls)==5`. Error messages and semantic intent of D-lock 5 preserved exactly.
- **Files modified:** `pkg/cluster/internal/loadbalancer/config_test.go`
- **Commit:** fe235b49
