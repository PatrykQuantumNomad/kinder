# Phase 57.1 Plan 02: Resume Wire-in Summary

**One-liner:** Phase 1.25 LB cds/lds reapply wired into lifecycle.Resume() via reapplyLBConfig + discoverLBIPv6 + 3x-retry with injectable backoff, closing the Phase 47 EOF regression.

## What Was Built

### New: `pkg/internal/lifecycle/lbreapply.go`

**reapplyLBConfig signature (D-lock 3):**
```go
func reapplyLBConfig(binaryName string, lb nodes.Node, cps []nodes.Node, logger log.Logger) error
```

**discoverLBIPv6 signature:**
```go
func discoverLBIPv6(binaryName string, lb nodes.Node, logger log.Logger) bool
```

**Package-level backoff var:**
```go
var defaultLBRetryBackoff = 1 * time.Second
```

Behavior:
- `lb == nil` → immediate return nil (single-CP no-op, SC3)
- Calls `discoverLBIPv6` → `docker inspect LB networks JSON` → `docker network inspect EnableIPv6`
- On any IPv6 discovery error → defaults to IPv4 + V(1) log (graceful fallback)
- Retry loop: 3 attempts; `time.Sleep(defaultLBRetryBackoff)` BETWEEN attempts (not before first)
- On exhaustion: `errors.Wrapf(lastErr, "LB reapply failed after 3 attempts; re-run kinder resume to retry", maxAttempts)`
- Calls `loadbalancer.WriteDynamicConfig(lb, cps, ipv6)` (Plan 01 helper via bridge)

### New: `pkg/cluster/loadbalancer/lbconfig.go` (bridge package)

Go's internal package rule prevents `pkg/internal/lifecycle` from importing `pkg/cluster/internal/loadbalancer` (different subtrees). Created a non-internal bridge at `pkg/cluster/loadbalancer/` that re-exports `WriteDynamicConfig`. Single source of truth preserved in the internal package.

- **Files modified:** `pkg/internal/lifecycle/lbreapply_test.go`
